About This Project

Smart Cities & Logistics — End-to-End ML Pipeline

RidePulse is a 5th-semester Data Structures & Algorithms academic project demonstrating an end-to-end machine learning pipeline for geospatial demand forecasting. It processes NYC taxi trip data, clusters pickup locations into 20 geographic zones using K-Means, engineers time-series features (lag, rolling mean), and trains an XGBoost regression model — all without data leakage.
